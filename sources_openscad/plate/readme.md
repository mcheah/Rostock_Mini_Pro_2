# Frame 2d files
These files are taken from the original [Rostick Mini release on thingiverse, by bwevans](https://www.thingiverse.com/thing:32850).  They have been simplified and modified to make compatible with the other Rostock Mini Pro updates.  The original .dxf files had segmented polygons instead of circular holes, which make it difficult to import into Fusion 360.
